# Chat

Переиспользуемый frontend беседы. Приложение предоставляет свой backend и данные;
Chat не запускает агентов, не подключает модели и не назначает инструменты.
Один и тот же интерфейс можно использовать для людей и для общения с ботами.

Публичные входы пакета `@zavx0z/chat`:

- `history` — ограниченное окно заголовков, тел и подробностей, загрузка при
  прокрутке и освобождение невидимых данных;
- `history/view` — область истории с сохранением позиции и штатной прокруткой;
- `header` — имя беседы с переименованием;
- `conversations` — список имён с созданием, выбором и удалением, не более
  32 строк одновременно;
- `composer` — ввод и отправка сообщения с местом для действий приложения;
- `content` — представление содержимого сообщения и медиа;
- `media` — выбор файлов и ограниченная подготовка вложений с предпросмотром.

Composer принимает файловый drop стандартными `DragEvent` и передаёт
`onFiles` собственный снимок списка файлов. Чтение через `filesToMedia`
применяет те же ограничения, что системный выбор файла; drop сам по себе
не отправляет сообщение. Bridge native Canvas принадлежит Browser,
а не отдельному экземпляру чата.

Элементы интерфейса берутся из Immersive UI. Chat собирает их в интерфейс беседы
в том же semantic Document; собственного Canvas или рендерера здесь нет.
Расширения приложения передаются через публичные данные, callbacks и JSX slots.
Настройки модели, права агента, инструменты, ACP и организация специалистов
принадлежат приложению Storybook и не входят в зависимости этого пакета.

Старые контракты `conversation`, `message` и `user` сохраняют проектирование
общего пользовательского API. Их групповые операции и права участников сами
по себе не означают наличия соответствующего backend.

## Локальная разработка

В этом Project существующий checkout Chat подключён обычной зависимостью,
без превращения в Git submodule. Связи Bun ведут на исходные checkout Immersive;
перед установкой нужны зарегистрированные `bun link` пакеты Immersive, затем
`bun install`. Для потребителя зарегистрировать Chat командой `bun link` в
этом каталоге и использовать `@zavx0z/chat` как зависимость.

Backend хранит полный источник истории. Frontend ограничивает resident данные
и создаваемый интерфейс; закрытие просмотра не удаляет сообщения и не отменяет
работу backend. Large payload загружается отдельно от списка бесед и заголовков.
